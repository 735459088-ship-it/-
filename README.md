# 施工管理平台

单文件、免安装：**双击 `index.html` 用浏览器打开即可使用**，电脑和手机都能用。

## 功能
| 模块 | 说明 |
| --- | --- |
| 首页 | 关键数字、智能提醒、各项目实际进度与计划进度对比 |
| 项目 | 工期与负责人；拖动滑块更新进度，到 100% 自动标记为「已完工」 |
| 施工日志 | 按日期分组显示；「智能生成」一键出草稿；「复用」可套用历史日志 |
| 安全质量 | 登记问题、按风险排序、逾期标红，一键标记「已整改」 |
| 材料 | 库存一键入库/出库，低于预警值自动提醒 |
| 数据 | 导出/导入备份（JSON），日志导出 CSV（Excel 可直接打开） |

## 智能
- **进度滞后预警**：按工期推算计划进度，与实际进度对比（滞后 5% 标黄，15% 标红），超期单独提醒
- **自动催填日志**：提醒当天还没写日志的项目
- **日志草稿**：自动汇总上次施工内容、待整改问题、库存预警和进度
- **整改期限建议**：按风险等级自动给出期限（高 1 天、中 3 天、低 7 天）
- **全局搜索**：`Ctrl+K`，项目、日志、问题、材料一起搜

## 快捷键
`Ctrl+K` 搜索 · `N` 快速新建 · `Esc` 关闭弹窗

## 数据说明
数据保存在当前浏览器的本地存储里，不会上传。换电脑或清理浏览器之前，请先到「数据」页导出备份。
